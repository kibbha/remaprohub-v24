Suppression du compte ReMaPro Hub + POS

Dernière mise à jour : 3 octobre 2026.

Cette page permet de demander la suppression d’un compte ReMaPro même si vous n’avez plus accès à l’application.

Depuis l’application

  1. Ouvrez Réglages.
  2. Ouvrez Confidentialité et compte.
  3. Choisissez Supprimer mon compte.
  4. Saisissez DELETE puis confirmez.

La procédure supprime le compte d’authentification, le profil et les appartenances aux établissements. Si vous êtes le seul membre d’une organisation, les données cloud de cette organisation sont également destinées à être supprimées.

Demander la suppression depuis le web

Si vous ne pouvez plus accéder à ReMaPro, envoyez votre demande à admin@remaprohub.com avec l’objet Demande de suppression de compte ReMaPro et indiquez l’adresse e-mail utilisée pour votre compte. Une vérification d’identité ou de contrôle du compte peut être demandée avant exécution afin d’éviter une suppression frauduleuse.

Données professionnelles partagées

Si une organisation possède d’autres membres actifs, les données professionnelles appartenant à cette organisation peuvent être conservées pour assurer la continuité de l’établissement. Le compte personnel et les accès de l’utilisateur supprimé sont retirés.

Données pouvant être conservées

Certaines informations peuvent être conservées lorsqu’une obligation légale, comptable, de sécurité, de prévention de la fraude ou de défense de droits l’exige. Elles ne sont alors conservées que pour la finalité et la durée applicables.

Abonnement

La suppression du compte ReMaPro ne remplace pas l’annulation d’un abonnement souscrit auprès d’une plateforme de facturation. L’abonnement doit également être annulé depuis le canal utilisé pour la souscription lorsque cela est nécessaire.
