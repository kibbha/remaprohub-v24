# ReMaPro Hub — development provenance

## Project direction

ReMaPro Hub has been developed under the product direction of the project owner, with iterative specifications, acceptance/rejection decisions, testing requirements and repository history retained through GitHub.

Development may include AI-assisted coding. AI assistance is treated as a development tool, not as a substitute for provenance review. The project does not claim that every isolated AI-generated expression is independently copyrightable; the compliance goal is to preserve the rights that can lawfully be owned and transferred in the overall ReMaPro product.

## Evidence retained in Git

- chronological commit history;
- issues/task specifications;
- test suites and release history;
- product documentation and architecture;
- IP/component/asset registers.

## Evidence to retain outside Git

- original design/logo source files and dated approvals;
- contractual assignments from future employees/contractors/agencies;
- receipts/licences for purchased assets/services;
- company formation/IP assignment documents if ownership changes;
- signed transaction documents if ReMaPro is sold.

## Contribution rule

No new human contributor should be treated as cleared merely because their code was committed. Update `CONTRIBUTOR_REGISTER.csv` and retain the appropriate written basis for commercial use and transfer.
