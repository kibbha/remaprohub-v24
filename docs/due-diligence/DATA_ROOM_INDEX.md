# ReMaPro acquisition / investment data-room index

Do not commit confidential documents, customer exports, passwords, secret keys or signed identity documents here. This index describes what should exist and where evidence should be retained.

## 01 — Corporate / ownership
- final legal owner of ReMaPro;
- company formation/shareholder records when applicable;
- written IP assignment into the company when applicable;
- domain and trade-mark ownership records.

## 02 — Intellectual property
- root proprietary licence;
- component register + release SBOMs;
- asset register and original evidence;
- contributor register and signed assignments;
- trade-mark searches/filings;
- development provenance record.

## 03 — Product / technology
- Hub/POS architecture;
- supported platforms and package IDs;
- database schema/migrations;
- API/Edge Function inventory;
- release history and signed build evidence;
- disaster recovery/backup procedures.

## 04 — Security
- SECURITY.md and security test evidence;
- RLS/permissions review;
- secret/key custody inventory (names/owners only here, never values);
- vulnerability remediation log;
- Android signing-key custody procedure.

## 05 — Privacy / data protection
- final privacy policies;
- data-flow and processing inventory;
- subprocessors/vendors;
- retention/deletion policy;
- breach/incident procedure;
- DPA/customer data-processing terms where applicable.

## 06 — Commercial
- pricing/subscription model;
- customer contracts/terms;
- RevenueCat/Google Play product mapping;
- payment-provider/terminal agreements;
- support/SLA commitments if any.

## 07 — Operations / providers
- GitHub ownership;
- Supabase organisation/project;
- domains/DNS/hosting;
- Google Play Console;
- RevenueCat;
- email/support systems;
- AI/API providers;
- analytics/monitoring;
- billing/payment providers.

## 08 — Business metrics
When operations begin, retain dated exports/definitions for:
- customers/restaurants;
- MRR/ARR;
- churn/retention;
- ARPU;
- acquisition costs where tracked;
- infrastructure cost;
- support volume;
- uptime/incidents.

## Transaction rule

Provide buyer/investor access progressively under the transaction NDA and only to the minimum information needed for each diligence stage. Transfer of repository access is not, by itself, a transfer of IP rights.
