# ReMaPro Hub V24.1.1

Base propre et fonctionnelle pour le management de restauration.

## V24.1.1
- Modules spécialisés réellement interactifs : HACCP, Équipe, RH, Documents, Recettes, Achats, Traçabilité, Pertes, Réservations et Paramètres.
- Accueil allégé : accès rapides limités aux fonctions essentielles ; tous les autres modules sont dans Plus.
- Formulaires et enregistrement local des données.
- Modification et suppression sur les éléments principaux.
- Migration silencieuse des données V24.0.x.
- Caméra stock et architecture Android conservées.
- TypeScript requis explicitement pour Capacitor.

## Installation
1. Déposer `ReMaPro_Hub_V24_1_1_READY.zip` dans le dépôt.
2. Ajouter `.github/workflows/install-v24-1-1.yml`.
3. Ajouter `.github/workflows/build-android-v24-1-1.yml`.
4. Lancer Install V24.1.1 puis Android V24.1.1.
