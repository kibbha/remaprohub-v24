Politique de confidentialité

Dernière mise à jour : 22 septembre 2026.

Données traitées

ReMaPro Hub peut traiter les informations de compte, les données de restaurant, les données opérationnelles, HACCP, stock, fournisseurs, finance, planning, documents RH et paramètres saisis par l’utilisateur. Les données de paiement sont traitées par Google Play et RevenueCat ; ReMaPro Hub ne reçoit pas les données complètes de carte bancaire.

Cloud et synchronisation

Lorsque la synchronisation cloud est utilisée, les données sont stockées via Supabase et protégées par authentification et règles d’accès. Les jetons de session de l’application Android sont conservés dans le stockage sécurisé de l’appareil lorsqu’il est disponible.

Intelligence artificielle

Les données ou images ne sont envoyées au service d’IA que lorsqu’un utilisateur lance volontairement une analyse ou une question. ReMaPro Hub n’envoie pas automatiquement les documents, photos ou données de restaurant à l’IA.

Achats et abonnements

Les abonnements Android sont gérés via Google Play, avec RevenueCat pour la gestion technique des droits d’abonnement.

Prestataires

Selon les fonctions utilisées, ReMaPro Hub peut s’appuyer sur Supabase pour l’authentification et les données cloud, Google Play pour la distribution et la facturation, RevenueCat pour les droits d’abonnement et OpenAI pour les requêtes d’IA initiées par l’utilisateur.

Conservation et suppression

L’utilisateur peut demander la suppression de son compte depuis Réglages → Confidentialité et compte → Supprimer mon compte. Si l’utilisateur est le seul membre d’une organisation, les données cloud de cette organisation peuvent également être supprimées. Les données professionnelles d’une organisation qui conserve d’autres membres peuvent être maintenues pour ces membres après suppression du compte personnel.

Vente de données

ReMaPro Hub ne vend pas les données personnelles.

Site web

Le site public remaprohub.com n’intègre pas de dispositif publicitaire ou de suivi marketing par défaut dans sa version actuelle.

Contact

Pour toute demande relative à la confidentialité : admin@remaprohub.com.
